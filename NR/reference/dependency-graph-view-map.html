Route

web/src/HUD.tsx entscheidet, welche Pane sichtbar ist.

Daten

View.uiResources liefert Ressourcen und Status für Nodes.

Echte statische Edges kommen nicht vollständig daraus.

Backend

Manifest.ResourceDependencies ist die statische Dependency-Quelle.

UIResourceStatus.resourceDependencies passt zum bestehenden UI-Read-Model und seinen WebSocket-Updates.

Node

Eine Custom Node repräsentiert eine Ressource und rendert SidebarItemView.

Status, Navigation und Build-Aktionen werden dadurch wiederverwendet.

Graph

Also keine Paketwahl üben; zuerst vorhandene Abhängigkeiten nutzen.

Navigation

Klicks auf Nodes navigieren später zur Resource Detail URL.
