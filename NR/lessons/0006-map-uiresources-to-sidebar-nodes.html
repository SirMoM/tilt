Lektion 6

Aus jeder UIResource wird eine Sidebar-Node

Ziel: Du wandelst alle Ressourcen aus view.uiResources in einzeln bedienbare React-Flow-Nodes um.

Status: begonnen. Die Graph Pane reicht alle UIResource-Objekte weiter; das Mapping auf SidebarItem und React-Flow-Nodes fehlt noch.

Das Mapping

SidebarItem verdichtet eine UIResource zusammen mit dem LogAlertIndex zu Status, Build-Daten, Hold und Aktionen. Diese vorhandene Verdichtung soll der Graph wiederverwenden.

Das Ergebnis pro Ressource ist eine React-Flow-Node mit id: item.name, type: "resource" und data.sidebarProps für SidebarItemView.

8-Minuten-Aufgabe

  1. Finde in SidebarResources.tsx, wie SidebarItem-Objekte erzeugt werden.
  2. Erzeuge für jede UIResource genau einen SidebarItem.
  3. Mappe jeden Eintrag auf eine React-Flow-Node vom Typ resource.
  4. Nutze zunächst Position { x: 0, y: 0 }; Dagre übernimmt später das Layout.

Retrieval Check

Was verdichtet eine UIResource für die Anzeige?

SidebarItem.

Was ist die stabile Node-ID?

Der Ressourcenname.

Warum bleibt der LogAlertIndex relevant?

Er beeinflusst angezeigte Statuswerte.

Primärquelle

Nutze web/src/SidebarItem.tsx, web/src/SidebarResources.tsx und web/src/SidebarItemView.tsx.
