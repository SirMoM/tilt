Lektion 4

SidebarItemView als React-Flow-Node wiederverwenden

Ziel: Eine Graph-Node repräsentiert genau eine Ressource und übernimmt die bewährte Darstellung und Interaktion der Sidebar.

Status: begonnen. Der Graph rendert bereits React-Flow-Nodes, verwendet aber noch keine registrierte Custom Node mit SidebarItemView.

Zwei Ebenen sauber trennen

Der Graph erhält alle Ressourcen. Jede React-Flow-Node erhält dagegen genau einen vorbereiteten SidebarItem und rendert damit SidebarItemView.

So bleiben Status, Build-Animation, Restart-Aktion, Disabled-Zustand und Navigation zur Ressourcenansicht erhalten. React Flow ergänzt nur id, position, data und Handles für das Graph-Layout.

8-Minuten-Aufgabe

  1. Lies web/src/SidebarItemView.tsx ab SidebarItemViewProps.
  2. Markiere Navigation, Build-Aktion, Statusanzeige und Disabled-Variante.
  3. Definiere eine React-Flow-Datenform mit einem Feld sidebarProps: SidebarItemViewProps.
  4. Erstelle eine Custom Node, die Handles und <SidebarItemView {...data.sidebarProps} /> rendert.
  5. Registriere sie außerhalb der Renderfunktion über nodeTypes.
